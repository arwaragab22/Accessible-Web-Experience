♿ Accessibility Enhancement Project
This project focuses on improving accessibility for users with disabilities, specifically those who are blind or have color blindness.

💡 What I Did
Although I did not design the original interface, I worked on enhancing its functionality to better support users with special needs.

🔊 Key Features
Speech Recognition (using SpeechRecognition.js):
The website responds to voice commands and reads out the content aloud, simulating an audio-driven interaction.

Voice Feedback:
Each element that appears on the screen is read aloud to assist visually impaired users.

Accessibility Settings:
Users can customize the website's accessibility settings (e.g., contrast, font size, etc.), which are saved in the browser’s local storage to persist between sessions.

Support for Blind and Color-Blind Users:
Special attention was given to improving the experience for both fully blind users and those with color vision deficiencies.
